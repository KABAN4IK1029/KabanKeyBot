# 📥 ИНСТРУКЦИЯ ПО УСТАНОВКЕ Kaban Key Bot

**Всё займёт 5–10 минут. Делайте по шагам, ничего не пропускайте.**

---

## ШАГ 1. ПОДГОТОВКА (один раз)

### 1. Установите Python
1. Перейдите на https://www.python.org/downloads/windows/
2. Скачайте **Python 3.11.x** (Windows installer 64-bit)
3. Запустите установщик
4. **ВАЖНО:** поставьте галочку `[x] Add python.exe to PATH`
5. Нажмите "Install Now"

### 2. Создайте бота в Telegram
1. Напишите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Придумайте имя для бота (например: "Kaban Key Bot")
4. Придумайте username (например: `kaban_key_bot`)
5. BotFather пришлёт **ТОКЕН** (длинная строка вида `123456789:AAH...`)
6. **Скопируйте этот токен** — он понадобится на Шаге 3

---

## ШАГ 2. РАСПАКОВКА

1. Скачайте архив с проектом
2. Распакуйте его в любую папку (например: `C:\KabanKeyBot`)
3. Лучше, чтобы в пути к папке не было русских букв и пробелов

---

## ШАГ 3. НАСТРОЙКА ТОКЕНА (максимально просто)

### Способ А — через установщик (рекомендуется)
1. Дважды нажмите на `setup/install.bat`
2. Программа сама установит библиотеки
3. Откроется мастер настройки — вставьте токен от @BotFather
4. Нажмите Enter и сохраните

### Способ Б — вручную
1. Скопируйте файл `.env.example` в `.env` (в той же папке)
2. Откройте `.env` в Блокноте
3. Найдите строку `TELEGRAM_BOT_TOKEN=` и вставьте токен после знака равно
4. Сохраните файл и закройте Блокнот

---

## ШАГ 4. ПЕРВЫЙ ЗАПУСК

1. Дважды нажмите на `setup/install.bat` (или `start.bat` если он есть)
2. Дождитесь установки библиотек (первый раз может занять 2–5 минут)
3. Бот запустится — вы увидите сообщение "✅ Бот запущен и готов к работе!"

Чёрное окно не закрывайте, пока бот работает.

---

## ШАГ 5. АКТИВАЦИЯ АДМИНА

1. Напишите своему боту в Telegram команду `/start`
2. **Первый пользователь автоматически становится админом**
3. Используйте `/admin` для открытия панели управления с кнопками

---

## АДМИН-ПАНЕЛЬ

После `/admin` вы увидите кнопки:

- 🔑 **Сгенерировать ключ** — создать новый ключ
- 📊 **Статистика** — сколько ключей создано и использовано
- 🏷 **Изменить префикс** — изменить начало ключей (сейчас `KABAN4IK1029`)
- 👥 **Список админов** — кто имеет права админа
- 📋 **Последние ключи** — история созданных ключей

---

## КОМАНДЫ ДЛЯ ПОЛЬЗОВАТЕЛЕЙ

| Команда | Что делает |
|---------|------------|
| `/start` | Запуск бота и регистрация |
| `/help` | Список всех команд |
| `/key KABAN4IK1029-XXXX-XXXX-XXXX` | Активировать ключ |
| `/mykey` | Показать ваши ключи |
| `/status` | Статус системы |

---

## ЧАСТЫЕ ПРОБЛЕМЫ

**Ошибка "неизвестная команда" при запуске install.bat**
→ Python не установлен или не стоял галочкой "Add python.exe to PATH". Переустановите Python.

**Бот не отвечает на команды**
→ Проверьте, что токен в `.env` вставлен без пробелов и переносов строк.

**Ошибка при подключении к AWS**
→ Проверьте настройки AWS в файле `.env` (регион, ключи доступа).

**Первый пользователь не стал админом**
→ Убедитесь, что таблица DynamoDB создана и бот имеет к ней доступ.
