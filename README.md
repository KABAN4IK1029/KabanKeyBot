# Kaban Key Bot

Генератор и система управления ключами формата `KABAN4IK1029-XXXX-XXXX-XXXX` для Telegram-бота.

## Возможности

- 🔑 Генерация ключей в формате `PREFIX-XXXX-XXXX-XXXX`
- 🏷 Настраиваемый префикс (меняет только админ)
- 👤 Первый пользователь автоматически становится админом
- 🛠 Админ-панель с инлайн-кнопками (по референсу AfkToken)
- ☁ Серверная часть на AWS Lambda + DynamoDB
- 🚀 Простая установка (даже для людей, далеких от программирования)

## Архитектура

```
KabanKeyBot/
├── bot/              # Telegram bot (клиент)
│   ├── main.py       # Точка входа
│   ├── handlers.py   # Обработчики команд
│   ├── admin_panel.py # Админ-панель с кнопками
│   ├── keygen.py     # Генерация ключей
│   └── db.py         # Работа с DynamoDB
├── server/           # AWS Lambda + SAM
│   ├── template.yaml # Инфраструктура (CloudFormation/SAM)
│   └── functions/    # Lambda функции
├── setup/            # Установщик
│   ├── install.bat   # Автоустановка (для Windows)
│   └── setup_wizard.py # Мастер настройки
├── .env.example      # Шаблон конфигурации
├── requirements.txt  # Зависимости Python
└── INSTALL.md        # Подробная инструкция по установке
```

## Быстрый старт (Windows)

1. Скачайте архив проекта или клонируйте с GitHub
2. Запустите `setup/install.bat`
3. Следуйте инструкциям мастера настройки
4. Вставьте токен бота от @BotFather в файл `.env`
5. Запустите `python bot/main.py`

Первый человек, который напишет боту, станет админом.

## Админ-команды

| Команда | Описание |
|---------|----------|
| `/admin` | Открыть панель управления |
| `/genkey` | Сгенерировать новый ключ |
| `/prefix <код>` | Изменить префикс ключей |
| `/stats` | Статистика системы |
| `/admins` | Список админов |

## Пользовательские команды

| Команда | Описание |
|---------|----------|
| `/start` | Запуск и регистрация |
| `/help` | Список команд |
| `/key <код>` | Активировать ключ |
| `/mykey` | Ваши ключи |
| `/status` | Статус системы |
